# Словоизменение

Каждый разбор знает свою лексему - все формы слова с той же леммой. По разбору можно получить список форм, нужную форму по признакам UD или форму, согласованную с количеством.

## Формы лексемы { #forms }

`forms` возвращает формы лексемы в порядке словаря - это такие же разборы, как у `analyze`, с вероятностью 1:

``` python
>>> from rumorph import Analyzer
>>> morph = Analyzer()
>>> cat = morph.analyze("кошка")[0]
>>> [form.word for form in cat.forms()]
['кошка', 'кошки', 'кошке', 'кошку', 'кошкой', 'кошкою', 'кошке', 'кошки', 'кошек', 'кошкам', 'кошек', 'кошками', 'кошках']
>>> form = cat.forms()[8]
>>> form.word, dict(form.feats)
('кошек', {'Animacy': 'Anim', 'Case': 'Gen', 'Gender': 'Fem', 'Number': 'Plur'})
```

Лексема определяется леммой, поэтому следует соглашениям UD о леммах: у «Ивановой» лексема - женские формы фамилии «Иванова», у «важнейшего» - формы превосходной степени. Варианты форм отличаются пометами: «кошкою» - `V-oy`, второй предложный падеж «в лесу» - `loc2` (признак `Case=Loc` у него тот же, что у «о лесе»).

## Форма по признакам { #inflect }

`inflect` принимает признаки UD именованными аргументами и возвращает словоформу:

``` python
>>> cat.inflect(Case="Gen")
'кошки'
>>> cat.inflect(Case="Gen", Number="Plur")
'кошек'
>>> verb = morph.analyze("читал")[0]
>>> verb.inflect(Gender="Fem"), verb.inflect(Tense="Pres", Person="3", Number="Plur"), verb.inflect(VerbForm="Inf")
('читала', 'читают', 'читать')
>>> morph.analyze("новый")[0].inflect(Degree="Cmp")
'новее'
```

Признаки, которые не названы, по возможности сохраняются: «кошка» в родительном падеже - «кошки», а не «кошек». Если у лексемы нет формы с такими признаками, `inflect` бросает `FormNotFoundError` - подкласс `LookupError`; если признака или значения нет в словаре (опечатка вроде `Case="Genitive"`), - `ValueError` со списком допустимых значений.

## Согласование с количеством { #agree }

`agree` согласует существительное, прилагательное, местоименное прилагательное или причастие с количеством:

``` python
>>> ruble = morph.analyze("рубль")[0]
>>> [f"{n} {ruble.agree(n)}" for n in (1, 2, 5, 21)]
['1 рубль', '2 рубля', '5 рублей', '21 рубль']
```

Падеж разбора сохраняется: «рублях» с числом 2 - «рублях» («о 2 рублях»), винительный падеж одушевленных - «вижу двух котов». Прилагательные согласуются по роду: «две новые», «два новых». У слов без единственного числа берется множественное: «1 сутки», «2 суток». Если нужной формы нет («5 молока») или слово не согласуется с количеством (глагол, наречие), `agree` бросает `FormNotFoundError`.

Словоформы `forms`, `inflect` и `agree` - в написании словаря: в нижнем регистре и с буквой «ё», если она есть в словаре.
