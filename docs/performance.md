# Сравнение

ruMorph разбирает слово без контекста, как pymorphy3 и mystem, и среди них он самый точный: на трех тестовых наборах UD у первого разбора верны часть речи и лемма у 90-94 % слов против 79-83 % у pymorphy3 и mystem. И самый быстрый: 648 тыс. токенов в секунду, в 28 раз быстрее pymorphy3 и в 20 раз быстрее mystem, а загрузка занимает 5 мс. Теггер с контекстом Stanza точнее в признаках, но в 230 раз медленнее и загружается 2,6 с.

## Качество { #quality }

Эталон - тестовые части трибанков [UD_Russian-SynTagRus](https://github.com/UniversalDependencies/UD_Russian-SynTagRus), [UD_Russian-Taiga](https://github.com/UniversalDependencies/UD_Russian-Taiga) и [UD_Russian-GSD](https://github.com/UniversalDependencies/UD_Russian-GSD) из релиза UD 2.18: каждая система получает их токены, знаки препинания не считаются, леммы сравниваются без учета регистра и с «е» вместо «ё». Соглашения разметки у трибанков разные, поэтому сравнивать стоит системы на одном наборе, а не наборы между собой.

### Без контекста { #context-free }

Доля слов, у которых верны часть речи и лемма первого разбора, в скобках - хотя бы одного из разборов, %:

| Система | SynTagRus | Taiga | GSD |
| :------ | :-------- | :---- | :-- |
| ruMorph | **93,7** (97,5) | **90,5** (94,9) | **92,1** (95,4) |
| pymorphy3 | 81,4 (86,4) | 79,8 (85,3) | 83,1 (86,2) |
| mystem | 81,9 (86,4) | 79,4 (83,8) | 79,9 (83,9) |

pymorphy3 и mystem размечают по своим правилам, их части речи переведены в UD простой таблицей: существительное - `NOUN`, а с граммемой имени, фамилии или топонима - `PROPN`, местоимение-существительное - `PRON` и т. д. Поэтому часть их ошибок - расхождения соглашений, а не разбора: «быть» у них глагол, а в UD - `AUX`, «который» у pymorphy3 - прилагательное, а в UD - `DET`. ruMorph следует соглашениям UD. mystem не разбирает числа цифрами.

## Скорость { #speed }

### Разбор текста { #text }

Время разбора текста вместе с импортом и загрузкой системы в новом процессе, секунд, по обеим осям - логарифмическая шкала:

![Время разбора текста с загрузкой от объема текста](img/speed.svg)

На коротком тексте почти все время уходит на загрузку: ruMorph отвечает за 6 мс, pymorphy3 и mystem - за 25-40 мс, Slovnet - за 0,2 с, spaCy - за 1,1 с, Stanza - за 2,6 с. На длинном решает скорость разбора, токенов в секунду без загрузки, больше - лучше:

| Система | Токенов в секунду |
| :------ | :---------------- |
| ruMorph | **647 922** |
| Slovnet (Natasha) | 45 581 |
| mystem | 33 171 |
| pymorphy3 | 23 216 |
| spaCy ru_core_news_sm | 6 977 |
| Stanza | 2 795 |

### Операции { #operations }

Тысяч слов или разборов в секунду в сравнении с pymorphy3, больше - лучше:

| Операция | ruMorph | pymorphy3 | pymorphy3[fast] |
| :------- | :------ | :-------- | :-------------- |
| Разбор словоформы: `analyze` в цикле, `parse` | 732 | 20 | 105 |
| Разбор списка: `analyze_many` | 754 | - | - |
| Лемматизация: `lemmatize`, `parse(word)[0].normal_form` | 1 404 | 22 | 170 |
| Лемматизация в 4 потоках: `lemmatize` | 4 275 | - | - |
| Форма по признакам: `inflect(Case="Gen")`, `inflect({"gent"})` | 1 399 | 76 | 76 |
| Согласование с количеством: `agree(5)`, `make_agree_with_number(5)` | 1 417 | 85 | 85 |
| Формы лексемы: `forms()`, `lexeme` | 101 | 32 | 32 |

Списки слов разбираются без GIL, поэтому несколько потоков с одним анализатором работают параллельно.

## Загрузка и память { #memory }

| | ruMorph | pymorphy3 | pymorphy3[fast] |
| :- | :------ | :-------- | :-------------- |
| Импорт и загрузка словаря | 4 мс | 30 мс | 31 мс |
| Прирост памяти процесса | 16,0 МБ | 34,5 МБ | 25,5 МБ |
| Каждый следующий процесс | 1,4 МБ | 32,5 МБ | 23,1 МБ |

Анализаторы с одним файлом словаря в процессе делят словарь. Файл словаря отображается в память, поэтому процессы `multiprocessing`, joblib или воркеры веб-сервера делят и его: каждый следующий процесс добавляет только собственные таблицы анализатора.

## Как измерено { #method }

- Качество и разбор текста - скрипт [`scripts/compare.py`](https://github.com/SergeyShk/ruMorph/blob/master/scripts/compare.py): `uv run scripts/compare.py build/compare --chart docs/img/speed.svg`. Он ставит системы в отдельное окружение с закрепленными версиями, скачивает тестовые части трибанков, модели Slovnet и mystem с проверкой контрольных сумм и разбирает эталонные токены. Таблицы перевода частей речи, падежа и числа pymorphy3 и mystem в UD - в начале скрипта.
- Версии: Python 3.11, ruMorph 0.3.0.dev8, pymorphy3 2.0.6 со словарем pymorphy3-dicts-ru 2.4.417150.4580142, mystem 3.1 через pymystem3 0.2.0 без снятия омонимии (каждое слово отдельно), spaCy 3.8.16 с моделью ru_core_news_sm 3.8.0, Stanza 1.15.0 с моделью по умолчанию на процессоре (torch 2.14.1), Slovnet 0.6.0 с моделями slovnet_morph_news_v1 и navec_news_v1. Компьютер - Apple M3 Pro, macOS 26.
- Скорость разбора текста - 157 706 токенов тестовой части SynTagRus со знаками препинания в одном потоке: токенов в секунду - лучший из двух разборов всей части после загрузки, точки графика - импорт, загрузка и разбор первых 10-100 000 токенов в новом процессе.
- Операции и память - ruMorph 0.2.0, pymorphy3 2.0.6, `pymorphy3[fast]` - то же с расширением DAWG на C++; 128 251 словоформа тестовой части SynTagRus без знаков препинания, лучшее из трех прогонов в одном потоке, кроме строки с потоками. `inflect` - родительный падеж первых разборов с падежом, `agree` - первые разборы существительных с числом 5, `forms` - первые разборы первых 20 000 слов. Память - прирост резидентной памяти процесса (`ps -o rss`) после импорта и создания анализатора, время - импорт, создание анализатора и первый разбор; следующий процесс - прирост памяти, которую процесс не делит с другими (USS), в каждом из четырех процессов `multiprocessing`.
