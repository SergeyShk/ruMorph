# Скорость и память

Разбор и лемматизация в ruMorph примерно в 5 раз быстрее, чем в pymorphy3 с ускорением `pymorphy3[fast]`, и в 25-40 раз быстрее, чем в pymorphy3 без него; `inflect` и `agree` - в 15-18 раз. Списки слов разбираются без GIL, поэтому несколько потоков с одним анализатором работают параллельно. Словарь загружается за 24 мс и занимает в памяти столько же, сколько у `pymorphy3[fast]`.

## Скорость { #speed }

Тысяч слов или разборов в секунду, больше - лучше:

| Операция | ruMorph | pymorphy3 | pymorphy3[fast] |
| :------- | :------ | :-------- | :-------------- |
| Разбор словоформы: `analyze` в цикле, `parse` | 483 | 20 | 106 |
| Разбор списка: `analyze_many` | 505 | - | - |
| Лемматизация: `lemmatize`, `parse(word)[0].normal_form` | 889 | 21 | 172 |
| Лемматизация в 4 потоках: `lemmatize` | 2 229 | - | - |
| Форма по признакам: `inflect(Case="Gen")`, `inflect({"gent"})` | 1 354 | 76 | 76 |
| Согласование с количеством: `agree(5)`, `make_agree_with_number(5)` | 1 270 | 85 | 86 |
| Формы лексемы: `forms()`, `lexeme` | 56 | 32 | 32 |

## Загрузка и память { #memory }

| | ruMorph | pymorphy3 | pymorphy3[fast] |
| :- | :------ | :-------- | :-------------- |
| Импорт и загрузка словаря | 24 мс | 31 мс | 31 мс |
| Прирост памяти процесса | 26 МБ | 35 МБ | 26 МБ |

Анализатор достаточно создать один раз: каждый новый анализатор загружает словарь заново. Процессы `multiprocessing` и joblib загружают словарь каждый в своей памяти.

## Как измерено { #method }

- Компьютер - Apple M3 Pro, macOS 26, Python 3.11; ruMorph 0.1.0.dev9, pymorphy3 2.0.6 со словарем pymorphy3-dicts-ru 2.4.417150.4580142; `pymorphy3[fast]` - то же с расширением DAWG на C++.
- Слова - 128 251 словоформа тестовой части [UD_Russian-SynTagRus](https://github.com/UniversalDependencies/UD_Russian-SynTagRus) без знаков препинания, в порядке текста. Время - лучшее из трех прогонов в одном потоке, кроме строки с потоками.
- `inflect` - родительный падеж первых разборов с падежом, `agree` - первые разборы существительных с числом 5, `forms` - первые разборы первых 20 000 слов.
- Память - прирост резидентной памяти процесса (`ps -o rss`) после импорта библиотеки и создания анализатора, время - импорт, создание анализатора и первый разбор.
