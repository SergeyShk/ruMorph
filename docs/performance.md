# Скорость и память

Разбор и лемматизация в ruMorph примерно в 5 раз быстрее, чем в pymorphy3 с ускорением `pymorphy3[fast]`, и в 24-37 раз быстрее, чем в pymorphy3 без него; `inflect` и `agree` - в 15-18 раз. Списки слов разбираются без GIL, поэтому несколько потоков с одним анализатором работают параллельно. Словарь загружается за 14 мс, вдвое быстрее, чем в pymorphy3, и занимает в памяти меньше, чем у `pymorphy3[fast]`.

## Скорость { #speed }

Тысяч слов или разборов в секунду, больше - лучше:

| Операция | ruMorph | pymorphy3 | pymorphy3[fast] |
| :------- | :------ | :-------- | :-------------- |
| Разбор словоформы: `analyze` в цикле, `parse` | 474 | 20 | 105 |
| Разбор списка: `analyze_many` | 493 | - | - |
| Лемматизация: `lemmatize`, `parse(word)[0].normal_form` | 810 | 22 | 170 |
| Лемматизация в 4 потоках: `lemmatize` | 2 345 | - | - |
| Форма по признакам: `inflect(Case="Gen")`, `inflect({"gent"})` | 1 400 | 76 | 76 |
| Согласование с количеством: `agree(5)`, `make_agree_with_number(5)` | 1 307 | 85 | 85 |
| Формы лексемы: `forms()`, `lexeme` | 57 | 32 | 32 |

## Загрузка и память { #memory }

| | ruMorph | pymorphy3 | pymorphy3[fast] |
| :- | :------ | :-------- | :-------------- |
| Импорт и загрузка словаря | 14 мс | 30 мс | 31 мс |
| Прирост памяти процесса | 21,5 МБ | 34,5 МБ | 25,5 МБ |

Анализаторы с одним файлом словаря в процессе делят словарь, а процессы `multiprocessing` и joblib загружают его каждый в своей памяти.

## Как измерено { #method }

- Компьютер - Apple M3 Pro, macOS 26, Python 3.11; ruMorph 0.1.0.dev14, pymorphy3 2.0.6 со словарем pymorphy3-dicts-ru 2.4.417150.4580142; `pymorphy3[fast]` - то же с расширением DAWG на C++.
- Слова - 128 251 словоформа тестовой части [UD_Russian-SynTagRus](https://github.com/UniversalDependencies/UD_Russian-SynTagRus) без знаков препинания, в порядке текста. Время - лучшее из трех прогонов в одном потоке, кроме строки с потоками.
- `inflect` - родительный падеж первых разборов с падежом, `agree` - первые разборы существительных с числом 5, `forms` - первые разборы первых 20 000 слов.
- Память - прирост резидентной памяти процесса (`ps -o rss`) после импорта библиотеки и создания анализатора, время - импорт, создание анализатора и первый разбор.
