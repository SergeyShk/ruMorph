# Разбор словоформ

Анализатор находит для словоформы все варианты разбора по словарю OpenCorpora и упорядочивает их по вероятности.

## Анализатор { #analyzer }

``` python
>>> from rumorph import Analyzer
>>> morph = Analyzer()
```

Словарь загружается при создании анализатора за несколько миллисекунд. Достаточно создать анализатор один раз и пользоваться им во всей программе, в том числе из нескольких потоков. По умолчанию берется словарь из пакета, другой файл словаря передается аргументом `path`.

## Разборы словоформы { #analyze }

`analyze` возвращает разборы словоформы по убыванию вероятности:

``` python
>>> for analysis in morph.analyze("стали")[:2]:
...     print(analysis.word, analysis.lemma, round(analysis.prob, 3))
стали стать 0.975
стали сталь 0.011
```

| Поле | Значение |
|---|---|
| `word` | словоформа в написании словаря: с буквой «ё», если она есть в словаре |
| `lemma` | начальная форма |
| `prob` | вероятность разбора; сумма по всем разборам словоформы равна 1 |
| `source` | откуда взят разбор: `"dictionary"` - словоформа есть в словаре |

Регистр не важен, а буква «е» может обозначать «ё»: `analyze("ЕЖ")` возвращает разборы словоформы «ёж». Для слова, которого нет в словаре, список пуст.

## Списки слов { #lists }

`analyze_many` разбирает набор словоформ, `lemmatize` возвращает леммы их самых вероятных разборов:

``` python
>>> morph.lemmatize(["Мы", "стали", "друзьями"])
['мы', 'стать', 'друг']
```

Слово, которого нет в словаре, `lemmatize` возвращает в нижнем регистре. Оба метода принимают любой набор слов - список, кортеж, генератор - и разбирают его без GIL: несколько потоков с одним анализатором работают параллельно.

## Словарь { #dictionary }

`is_known` проверяет, есть ли словоформа в словаре. Словарь - OpenCorpora, около 3,1 млн словоформ; вероятности разборов взяты из корпуса OpenCorpora, у словоформ, которых в корпусе нет, разборы равновероятны.
