# Разбор словоформы

Разбор - объект `Analysis`, который возвращают методы [анализатора](analyzer.md) `analyze` и `analyze_many`: лемма, часть речи и признаки [Universal Dependencies](https://universaldependencies.org/), вероятность и источник разбора. Разборы неизменяемы; их можно сравнивать (вероятность в сравнении не участвует, поэтому разбор равен своей форме из `forms()`; исключение - разбор, слитый из лексем с разными пометами, как «однако» с пометой `Prnt` и без нее: его форма может нести пометы другой лексемы), класть в множества и сохранять через pickle. Формы слова по разбору дают методы `forms`, `inflect` и `agree` - см. [Словоизменение](inflection.md).

=== "Код"

    ``` python
    from rumorph import Analyzer

    morph = Analyzer()
    analysis = morph.analyze("стали")[0]
    analysis.lemma, analysis.pos, analysis.feats, analysis.labels
    ```

=== "Результат"

    ```
    ('стать',
     'VERB',
     {'Aspect': 'Perf',
      'Mood': 'Ind',
      'Number': 'Plur',
      'Tense': 'Past',
      'VerbForm': 'Fin',
      'Voice': 'Act'},
     frozenset({'intr'}))
    ```

## Атрибуты { #attributes }

| Атрибут | Тип | Описание |
| :------ | :-- | :------- |
| `word` | `str` | Словоформа в написании словаря: с буквой «ё», если она есть в словаре; у разборов по правилам и угаданных - как в тексте, но у угаданных с «ё» из окончания словарной формы («пингвиненка» - «пингвинёнка») |
| `lemma` | `str` | Начальная форма |
| `pos` | `str` | Часть речи UD: `NOUN`, `VERB`, `ADJ`, `DET`, `ADP` и т. д. |
| `feats` | `dict[str, str]` | Признаки UD: `{"Case": "Gen", "Number": "Sing"}`; каждый раз новый словарь, его изменение не меняет разбор |
| `labels` | `frozenset[str]` | Пометы словаря, у которых нет признака UD: `Infr` (разговорное) и др. |
| `prob` | `float` | Вероятность разбора; сумма по всем разборам словоформы равна 1 |
| `source` | `str` | Откуда взят разбор: `"dictionary"` - словоформа есть в словаре, `"rule"` - [разбор по правилу](#rules), `"guess"` - [угаданный разбор](#guess) незнакомого слова |

## Части речи и признаки { #ud }

Части речи и признаки следуют руководству [Universal Dependencies](https://universaldependencies.org/u/pos/), а где оно молчит - соглашениям крупнейшего русского трибанка [UD_Russian-SynTagRus](https://github.com/UniversalDependencies/UD_Russian-SynTagRus), поэтому результат можно сравнивать с разметкой spaCy, Stanza и других инструментов на UD. По руководству будущее время «быть» («будет») - `Tense=Fut`, а `Voice=Mid` - только у возвратных глаголов («стать» - `Voice=Act`). Отличия от частей речи OpenCorpora:

- «который», «этот», «свой», «весь», «такой» и другие местоименные прилагательные - `DET`;
- «быть» и «бы» - `AUX`;
- вводные слова «однако», «например», «конечно» - `ADV`;
- «можно», «надо», «нельзя» - `VERB` без признаков;
- предлоги - `ADP`, сочинительные союзы - `CCONJ`, подчинительные - `SCONJ`, частицы - `PART`.

Если часть речи слова зависит от контекста, у него есть оба разбора: «есть» - `AUX` и `VERB` («у меня есть»), «бы» - `AUX` и `PART`, «это» - `PRON` и `PART` («это он сделал»), «один» - `NUM` и `DET` («одна женщина»), «друг» - `NOUN` и местоимение `PRON` с `PronType=Rcp` («друг друга»), «всё» - `PRON` и `PART` («всё ещё»), глагол на -ся - `Voice=Mid` и пассив `Voice=Pass` с невозвратной леммой («используется» - «использоваться» и «использовать»), «раньше», «лучше» - `ADJ` и `ADV` в сравнительной степени (леммы «ранний» и «рано», «хороший» и «хорошо»). У «двух», «двум», «двумя» - разборы всех трех родов.

Признаки: падеж, число, род, одушевленность, лицо, время, вид, наклонение, залог, форма глагола, степень, краткая форма (`Variant=Short`), тип имени собственного (`NameType`), сокращение (`Abbr`), притяжательность (`Poss`), тип числительного (`NumType`) и его запись (`NumForm`), тип местоимения и местоименного наречия (`PronType`: «там» - `Dem`, «где» - `Rel`, «никогда» - `Neg`), возвратность (`Reflex`), несклоняемость (`InflClass=Ind`), отрицание (`Polarity=Neg`).

Леммы тоже следуют SynTagRus: у женских фамилий и отчеств лемма в женском роде («Ивановой» - «иванова»), превосходная степень остается превосходной («важнейшей» - «важнейший»), «денег» - «деньги», у сокращений лемма - полное слово, если оно одно, как требует руководство UD («млн» - «миллион», «г.» - «год», «англ.» - «английский», «др.» - «другой»), а сокращение нескольких слов остается («т.е.»). У существительных, у которых есть только множественное число, род - по склонению, как в SynTagRus: «выборы» - мужской, «сутки» - женский, «ворота» - средний; у несклоняемых («СМИ») и склоняемых как прилагательные («данные») рода нет. Если несколько разборов OpenCorpora в UD совпадают (союз и наречие «так»), они объединены в один, их вероятности сложены.

Пометы `labels` - граммемы [OpenCorpora](https://opencorpora.org/dict.php?act=gram), для которых в UD нет признака: стиль (`Infr`, `Slng`, `Arch`), качественное прилагательное (`Qual`), вводное слово (`Prnt` - у наречий, которые обычно вводные: «конечно», «кстати», «видимо»; глагол «кажется» и наречие «вообще» его не получают; в предложении - [`analyze_sentence`](analyzer.md#analyze_sentence) и [команда rumorph](cli.md) - у слов, которые часто не вводные, помета остается, только если рядом запятая или тире: «Однако, это так» - вводное, «Однако мы не стали», «промолвил он наконец» - нет), переходность (`tran`, `intr`), включенность говорящего в повелительном наклонении (`incl` - «пойдемте», `excl` - «иди»), второй предложный падеж (`loc2` - «в лесу») и другие.

## Токены вне словаря { #rules }

Числа, знаки, латиницу и сокращения анализатор разбирает по правилам, `source` у таких разборов - `"rule"`:

| Токен | Разбор |
| :---- | :----- |
| знаки препинания; символы `%`, `$`, `№`, `−`, эмодзи | `PUNCT`; `SYM` |
| числа цифрами и диапазоны: «15», «3,14», «10 000», «17:04», «1990-2000» | `NUM` с `NumForm=Digit`, `NumType=Card`; целое число может быть и порядковым `ADJ` с `NumType=Ord` - у чисел 1000-2100 (годы), кроме круглых сотен, это первый разбор, а 1900 и 2000 - тоже годы |
| числа и диапазоны с окончанием: «2005-го», «10-15-го», «5-ти» | порядковое `ADJ` с падежом и формами, как у «1-го», или количественное `NUM` |
| римские числа и диапазоны: «XX», «XIX-го», «II-III» | порядковое `ADJ` с `NumForm=Roman` |
| слова латиницей: «iPhone» | `X` с `Foreign=Yes` |
| инициалы: «А.», «А», «Дж.» | `PROPN` с `Abbr=Yes`: имя, отчество или фамилия |
| сокращения с точкой: «т.», «им.», «франц.», «тов.» | разборы словарного сокращения без точки; у частого сокращения, которого нет в словаре, - разборы похожего сокращения с полной леммой, и без точки («оч»); незнакомое («вин.») - `X` с леммой без точки |
| аббревиатуры капсом: «НКО» | `PROPN` или `NOUN` с `Abbr=Yes`; длинное слово капсом («ЧАТБОТАМИ») еще и угадывается как обычное |
| наречия «по-бурятски», «по-молодому» | `ADV` с `Degree=Pos` |
| прочие токены: «км/ч», «100%-ный» | `X` без признаков, лемма - токен в нижнем регистре |

Доли неоднозначных разборов взяты из частот в трибанках UD Taiga и GSD, доли имен собственных - с учетом регистра. Как в SynTagRus, «Земля», «Луна», «Солнце», «Кремль», «Дума» и несколько других нарицательных существительных с заглавной буквы - еще и имена собственные: «Земли» - прежде всего PROPN, «земли» - NOUN. Буквы «й» и «ё» в разложенной записи Unicode и неразрывный дефис приводятся к обычным, а знаки ударения (и в составленных буквах «ѐ», «ѝ»), управляющие (кроме пробельных) и невидимые символы (мягкий перенос, нулевой пробел U+200B, соединитель слов U+2060, BOM U+FEFF, метки направления текста) убираются: «Москва́» разбирается как «Москва», а `"при\u00adвет"` - как «привет». Латинские буквы, похожие на кириллические, в слове из кириллицы читаются как кириллица («cтали» с латинской «c» - «стали», «сáд» с латинской «á» - «сад», «ещë» с латинской «ë» - «ещё»), а кириллические в латинском слове - как латиница.

=== "Код"

    ``` python
    [(a.lemma, a.pos, a.feats["NumType"], round(a.prob, 2)) for a in morph.analyze("2026")]
    [(a.lemma, a.pos, a.feats["Case"]) for a in morph.analyze("2005-го")][:1]
    ```

=== "Результат"

    ```
    [('2026', 'ADJ', 'Ord', 0.98), ('2026', 'NUM', 'Card', 0.02)]
    [('2005-й', 'ADJ', 'Gen')]
    ```

## Незнакомые слова { #guess }

Разборы слова кириллицей, которого нет в словаре, анализатор угадывает: берет формы словарных слов с теми же окончаниями - их часть речи, признаки и словоизменение. Разборы слова в нижнем регистре выбирает среди этих форм модель, которая смотрит на все слово по буквам и обучена на самом словаре: «ноотропил» для нее существительное, а не прошедшее время глагола «ноотропить», «фрустрирующего» - причастие глагола «фрустрировать». Слово с заглавной буквы угадывается по самым частым формам с тем же окончанием. `source` у таких разборов - `"guess"`. Слово в нижнем регистре угадывается как нарицательное, слово с заглавной буквы - в основном как имя собственное: фамилия, имя, топоним, а слово на «-ский» - в основном как прилагательное. Аббревиатура с окончанием («МЭРТа») угадывается, как слово с заглавной. Слово в смешанном регистре с заглавными внутри строчного слова («прихАдите») или с суффиксом после аббревиатуры («КВНщиками», «ЗОЖное») угадывается как строчное, а слитное название («ЛайфНьюс») - как слово с заглавной. Строчное слово из одной-двух букв не угадывается: «ви» - `X`. Слово с заглавной буквы, которое есть в словаре только как редкое нарицательное существительное из Викисловаря, получает еще и угаданные разборы имени собственного: «Сенна» - прежде всего PROPN, «сенна» - NOUN. Слово с заглавной буквы, у которого в словаре нет имени собственного, а по окончанию угадывается фамилия на -ов, -ев, -ин или -ын, получает и ее разборы с долей 0,2, но не выше лучшего словарного разбора: «Рогожин» - прежде всего «рогожина» (NOUN), но в предложении «Он увидел Рогожина» - фамилия.

Слово через дефис разбирается по последней части: «крэш-тестов» - «крэш-тест», «IT-компании» - «it-компания»; если последняя часть - частица («сколь-нибудь»), то по первой. Слово с протяжкой или заиканием через дефис («Что-о», «не-е-ет», «Н-ну-у», «с-спасибо») получает разборы словарного слова без них, но без форм. Если изменяются обе части, лемма - из лемм частей: «стула-трансформера» - «стул-трансформер», форм у такого разбора нет. Слово с неизменяемым приложением «минимум», «максимум» или «люкс» разбирается по первой части, форм у такого разбора нет: «программы-минимум» - родительный падеж «программа-минимум». Слово с известной приставкой - «эко», «анти», «супер», «микро» и другими - разбирается по словарному слову без нее: «экодомов» - «экодом». Такие разборы тоже угаданные.

У угаданного разбора есть формы, с ним работают `forms`, `inflect` и `agree`; формы сохраняют заглавные буквы: «Мак-Киннона» в дательном - «Мак-Киннону», «ПИН-КОДОВ» - «ПИН-КОДАМ». Слово с частицей изменяется по первой части: «смотри-ка» во множественном числе - «смотрите-ка».

=== "Код"

    ``` python
    [(a.lemma, a.pos, a.feats.get("Case"), round(a.prob, 2)) for a in morph.analyze("донатеру")][:2]
    [morph.analyze(word)[0].lemma for word in ("ноотропил", "фрустрирующего")]
    guess = morph.analyze("Мартова")[0]
    guess.lemma, guess.pos, guess.feats["NameType"], guess.inflect(Case="Dat")
    morph.analyze("крэш-тестов")[0].lemma, morph.analyze("экодомов")[0].lemma
    ```

=== "Результат"

    ```
    [('донатер', 'NOUN', 'Dat', 0.67), ('донатер', 'NOUN', 'Dat', 0.25)]
    ['ноотропил', 'фрустрировать']
    ('мартов', 'PROPN', 'Sur', 'Мартову')
    ('крэш-тест', 'экодом')
    ```
