# Разбор словоформ

Анализатор находит для словоформы все варианты разбора по словарю OpenCorpora - начальную форму, часть речи и признаки [Universal Dependencies](https://universaldependencies.org/) - и упорядочивает их по вероятности.

## Анализатор { #analyzer }

``` python
>>> from rumorph import Analyzer
>>> morph = Analyzer()
```

Словарь загружается при создании анализатора за несколько миллисекунд. Достаточно создать анализатор один раз и пользоваться им во всей программе, в том числе из нескольких потоков. По умолчанию берется словарь из пакета, другой файл словаря передается аргументом `path`. Анализатор и разборы сохраняются через pickle, поэтому работают с multiprocessing и joblib: другой процесс загружает словарь один раз, сколько бы разборов он ни получил.

## Разборы словоформы { #analyze }

`analyze` возвращает разборы словоформы по убыванию вероятности:

``` python
>>> for analysis in morph.analyze("стали")[:2]:
...     print(analysis.lemma, analysis.pos, dict(analysis.feats), round(analysis.prob, 3))
стать VERB {'Aspect': 'Perf', 'Mood': 'Ind', 'Number': 'Plur', 'Tense': 'Past', 'VerbForm': 'Fin', 'Voice': 'Mid'} 0.975
сталь NOUN {'Animacy': 'Inan', 'Case': 'Gen', 'Gender': 'Fem', 'Number': 'Sing'} 0.011
```

| Поле | Значение |
|---|---|
| `word` | словоформа в написании словаря: с буквой «ё», если она есть в словаре; у разборов по правилам - как в тексте |
| `lemma` | начальная форма |
| `pos` | часть речи UD: `NOUN`, `VERB`, `ADJ`, `DET`, `ADP` и т. д. |
| `feats` | признаки UD - словарь `{"Case": "Gen", "Number": "Sing"}`; каждый раз новый, его изменение не меняет разбор |
| `labels` | пометы словаря, у которых нет признака UD, - `frozenset`: `{"Infr"}` (разговорное) |
| `prob` | вероятность разбора; сумма по всем разборам словоформы равна 1 |
| `source` | откуда взят разбор: `"dictionary"` - словоформа есть в словаре, `"rule"` - токена нет в словаре, разбор по правилу (см. [ниже](#rules)) |

Регистр не важен, а буква «е» может обозначать «ё»: `analyze("ЕЖ")` возвращает разборы словоформы «ёж».

## Части речи и признаки { #ud }

Части речи и признаки следуют [Universal Dependencies](https://universaldependencies.org/u/pos/) в соглашениях крупнейшего русского трибанка [UD_Russian-SynTagRus](https://github.com/UniversalDependencies/UD_Russian-SynTagRus), поэтому результат можно сравнивать с разметкой spaCy, Stanza и других инструментов на UD. Отличия от частей речи OpenCorpora:

- «который», «этот», «свой», «весь», «такой» и другие местоименные прилагательные - `DET`;
- «быть» и «бы» - `AUX`;
- вводные слова «однако», «например», «конечно» - `ADV`;
- «можно», «надо», «нельзя» - `VERB` без признаков;
- предлоги - `ADP`, сочинительные союзы - `CCONJ`, подчинительные - `SCONJ`, частицы - `PART`.

Признаки: падеж, число, род, одушевленность, лицо, время, вид, наклонение, залог, форма глагола, степень, краткая форма (`Variant=Short`), тип имени собственного (`NameType`), сокращение (`Abbr`), притяжательность (`Poss`), тип числительного (`NumType`) и его запись (`NumForm`), тип местоимения и местоименного наречия (`PronType`: «там» - `Dem`, «где» - `Rel`, «никогда» - `Neg`), возвратность (`Reflex`), несклоняемость (`InflClass=Ind`), отрицание (`Polarity=Neg`).

Леммы тоже следуют SynTagRus: у женских фамилий и отчеств лемма в женском роде («Ивановой» - «иванова»), превосходная степень остается превосходной («важнейшей» - «важнейший»), «денег» - «деньги». Если несколько разборов OpenCorpora в UD совпадают (союз и наречие «так»), они объединены в один, их вероятности сложены. Формы слова по разбору дают методы `forms`, `inflect` и `agree` - см. [Словоизменение](inflection.md).

Пометы `labels` - граммемы [OpenCorpora](https://opencorpora.org/dict.php?act=gram), для которых в UD нет признака: стиль (`Infr`, `Slng`, `Arch`), качественное прилагательное (`Qual`), вводное слово (`Prnt`), переходность (`tran`, `intr`), включенность говорящего в повелительном наклонении (`incl` - «пойдемте», `excl` - «иди»), второй предложный падеж (`loc2` - «в лесу») и другие.

## Токены вне словаря { #rules }

Числа, знаки, латиницу и сокращения анализатор разбирает по правилам, `source` у таких разборов - `"rule"`:

``` python
>>> [(a.lemma, a.pos, a.feats["NumType"], round(a.prob, 2)) for a in morph.analyze("2026")]
[('2026', 'ADJ', 'Ord', 0.94), ('2026', 'NUM', 'Card', 0.06)]
>>> [(a.lemma, a.pos, a.feats["Case"]) for a in morph.analyze("2005-го")][:1]
[('2005-й', 'ADJ', 'Gen')]
```

| Токен | Разбор |
|---|---|
| знаки препинания; символы `%`, `$`, `№`, `−`, эмодзи | `PUNCT`; `SYM` |
| числа цифрами: «15», «3,14», «10 000», «17:04» | `NUM` с `NumForm=Digit`, `NumType=Card`; целое число может быть и порядковым `ADJ` с `NumType=Ord` - у чисел 1000-2100 (годы), кроме круглых сотен, это первый разбор |
| числа с окончанием: «2005-го», «5-ти» | порядковое `ADJ` с падежом и формами, как у «1-го», или количественное `NUM` |
| римские числа: «XX» | порядковое `ADJ` с `NumForm=Roman` |
| слова латиницей: «iPhone» | `X` с `Foreign=Yes` |
| инициалы: «А.» | `PROPN` с `Abbr=Yes`: имя, отчество или фамилия |
| сокращения с точкой: «т.», «им.» | разборы словарного сокращения без точки |
| аббревиатуры капсом: «НКО» | `PROPN` или `NOUN` с `Abbr=Yes` |

Доли неоднозначных разборов взяты из частот в SynTagRus. Токен с пробелом (кроме числа), управляющим или невидимым символом разборов не получает. Незнакомые слова кириллицей пока не разбираются: для них список разборов пуст.

## Списки слов { #lists }

`analyze_many` разбирает набор словоформ, `lemmatize` возвращает леммы их самых вероятных разборов:

``` python
>>> morph.lemmatize(["Мы", "стали", "друзьями"])
['мы', 'стать', 'друг']
```

Токен без разборов `lemmatize` возвращает в нижнем регистре. Оба метода принимают любой набор слов - список, кортеж, генератор - и разбирают его без GIL: несколько потоков с одним анализатором работают параллельно.

## Словарь { #dictionary }

`is_known` проверяет, есть ли словоформа в словаре. Словарь - OpenCorpora, около 3,1 млн словоформ; вероятности разборов взяты из корпуса OpenCorpora: у слова, написанного через «е» вместо «ё», - частоты написания с «ё», у словоформ, которых в корпусе нет, разборы равновероятны.
